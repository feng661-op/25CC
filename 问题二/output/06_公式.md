# 问题 2 公式汇总（论文编写用）

> 本文集中了问题 2 用到的全部公式，每条给出：中文含义 + LaTeX 源码（可直接复制进论文/MathType）+ 直观形式。

---

## 一、达标时间定义

每位孕妇的达标时间 $T_i^*$ 定义为 Y 染色体浓度**首次达到或超过 4%** 的最早孕周：

**LaTeX**
```latex
T_i^* = \min\left\{\, GA \;:\; Y_i(GA) \ge 0.04 \,\right\}
```

**直观形式**
$$T_i^* = \min\{\, GA \;:\; Y_i(GA) \ge 0.04\,\}$$

---

## 二、区间删失 AFT 对数正态模型（核心）

达标时间服从对数正态分布，其位置由 BMI 决定：

**LaTeX**
```latex
\log T^* = \alpha + \beta \cdot BMI + \sigma \varepsilon,\quad \varepsilon \sim N(0,1)
```
等价地
```latex
T^* \sim \mathrm{LogNormal}\left(\alpha + \beta \cdot BMI,\ \sigma^2\right)
```

**直观形式**
$$\log T^* = \alpha + \beta\cdot BMI + \sigma\varepsilon,\quad \varepsilon\sim N(0,1)$$

**拟合结果**：$\alpha = 0.6142,\ \beta = 0.0440,\ \sigma = 0.5610$（$\beta>0$ 表示 BMI 越高达标越晚）。

---

## 三、删失数据的似然函数（统一处理三种删失）

记 $\mu_i = \alpha + \beta \cdot BMI_i$，$\Phi(\cdot)$ 为标准正态分布函数。三类删失对似然的贡献为：

**左删失**（首测已达标，$T^*\le L$）：
```latex
P(T^* \le L) = \Phi\!\left(\frac{\log L - \mu_i}{\sigma}\right)
```

**区间删失**（达标发生在两次检测 $a<T^*\le b$ 之间）：
```latex
P(a < T^* \le b) = \Phi\!\left(\frac{\log b - \mu_i}{\sigma}\right) - \Phi\!\left(\frac{\log a - \mu_i}{\sigma}\right)
```

**右删失**（始终未达标，$T^* > R$）：
```latex
P(T^* > R) = 1 - \Phi\!\left(\frac{\log R - \mu_i}{\sigma}\right)
```

**总似然**（取对数后最大化）：
```latex
\mathcal{L} = \prod_{i\in\text{左删失}} \Phi(\cdot)\ \prod_{i\in\text{区间删失}}\!\big[\Phi(\cdot)-\Phi(\cdot)\big]\ \prod_{i\in\text{右删失}}\!\big[1-\Phi(\cdot)\big]
```

---

## 四、达标时间的分位数

给定 BMI，个体达标时间的 $q$ 分位数为：

**LaTeX**
```latex
T_q(BMI) = \exp\left(\alpha + \beta\cdot BMI + z_q\,\sigma\right)
```

其中 $z_q$ 为标准正态 $q$ 分位点。常用：
```latex
T_{50}(BMI) = \exp\left(\alpha + \beta\cdot BMI\right)
```
```latex
T_{95}(BMI) = \exp\left(\alpha + \beta\cdot BMI + 1.645\,\sigma\right)
```

---

## 五、组混合达标比例（组级 CDF）

对某个 BMI 分组 $G$（含 $n_G$ 位孕妇），在孕周 $t$ 时组内**达标比例**为组内每个人达标概率的平均：

**LaTeX**
```latex
F_G(t) = \frac{1}{n_G}\sum_{i\in G} \Phi\!\left(\frac{\log t - \mu_i}{\sigma}\right),\qquad \mu_i = \alpha + \beta\cdot BMI_i
```

---

## 六、最佳 NIPT 时点（机会约束模型）

每组最佳时点取"在检测窗口内最早、且组达标比例达到 $q$"的孕周：

**LaTeX**
```latex
T_G^* = \min\left\{\, t \in [10,\ 25] \;:\; F_G(t) \ge q \,\right\},\qquad q = 0.95
```

若 $F_G(25) < q$，则标记为"常规检测窗口内无法满足"（不硬报 $>25$ 的数值）。

---

## 七、检测误差模型

Y 染色体浓度的单次测量值含测量噪声：

**LaTeX**
```latex
\hat{Y} = Y + \delta,\qquad \delta \sim N(0,\ \sigma_Y^2)
```

其中 $\sigma_Y \approx 0.005$（由"一次采血多次检测"的组内标准差估计，实测约 $0.0047$）。

蒙特卡洛分析：对每次检测的 $Y$ 加噪声 $\delta$ → 重建删失区间 → 重新拟合模型 → 重新求分组与时点，得到推荐孕周的分布与置信区间。

---

## 八、潜在风险函数（题目背景）

按题目给定的发现孕周风险等级：

**LaTeX**
```latex
R(t) = \begin{cases} \text{低},   & t \le 12 \\ \text{高},   & 13 \le t \le 27 \\ \text{极高}, & t \ge 28 \end{cases}
```

最佳时点取"满足可靠度后的最早 $t$"，即对应潜在风险最小，无需人为赋风险权重。

---

## 九、模型参数估计与不确定度（Bootstrap）

参数 $(\alpha,\beta,\sigma)$ 通过最大化 §三 的删失似然得到（MLE）；其标准误由孕妇级 Bootstrap（有放回重抽样 267 位孕妇、重复拟合）得到：

```latex
\mathrm{SE}(\theta) = \sqrt{\frac{1}{B-1}\sum_{b=1}^{B}\left(\hat\theta_{(b)} - \bar{\hat\theta}\right)^2}
```

实测：$\mathrm{SE}(\alpha)\approx 0.65,\ \mathrm{SE}(\beta)\approx 0.019,\ \mathrm{SE}(\sigma)\approx 0.076$。
