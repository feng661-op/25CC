# 问题 4 公式汇总（论文编写用）

## 1. 多标签化
$$Y_{k,i}=\begin{cases}1,&AB_i\text{ 包含 }T_k\\0,&\text{否则}\end{cases},\quad k\in\{13,18,21\}$$

## 2. 单 Z 基准（M0）
$$\hat Y^{base}_{ik}=I\big(|Z_{ik}|\ge t_k\big)$$
阈值 $t_k$ 在每个外层训练折内扫描，取使 $F_1$ 最大者。

## 3. Ridge Logistic（M1/M2）
$$\log\frac{p_{ik}}{1-p_{ik}}=\beta_{0k}+\sum_j\beta_{jk}x_{ij}$$
L2 惩罚目标：
$$\min_\beta\left[-\ell(\beta)+\lambda\sum_j\beta_j^2\right],\quad C=1/\lambda$$

## 4. 评价指标（类别不平衡）
$$\mathrm{Recall}=\frac{TP}{TP+FN},\quad \mathrm{Precision}=\frac{TP}{TP+FP}$$
$$F_1=\frac{2PR}{P+R},\quad F_\beta=(1+\beta^2)\frac{PR}{\beta^2P+R}$$
$$\mathrm{Brier}=\frac1n\sum_i(p_i-y_i)^2$$
PR-AUC 为 Precision–Recall 曲线下面积（随机基线 = 阳性率，非 0.5）。

## 5. 孕妇级 cluster bootstrap
以孕妇为整簇有放回重抽样 147 位（抽中即带入其全部记录），重复 1000 次，取 2.5%/97.5% 分位作 95% CI。

## 6. 最终判定
$$\mathcal A_i=\{k\in\{13,18,21\}:p_{ik}\ge c_k\}$$
据此输出"无异常 / T13 / T18 / T21 / 复合异常"。

## 7. 检测质量标记
$$Q_i=I(0.40\le GC_i\le0.60)$$
$Q_i=0$ 时标记"GC 范围外，可信度降低"（不改动异常判定，只加质量提示）。
