# 问题 4 符号设定

| 符号 | 含义 |
|---|---|
| $Y_{13},Y_{18},Y_{21}$ | 三个并行二元标签：AB 列是否包含 T13/T18/T21 |
| $Z_{13},Z_{18},Z_{21},Z_X$ | 13/18/21/X 号染色体 Z 值 |
| $C_X$ | X 染色体浓度（可能出现负值） |
| $GC,GC_{13},GC_{18},GC_{21}$ | 总体 / 各染色体 GC 含量 |
| $Reads,Map,Duplicate,Unique,Filter$ | 总读段数 / 比对比例 / 重复读段比例 / 唯一比对读段数 / 过滤比例 |
| $GW,BMI$ | 检测孕周 / 检测时 BMI |
| $M_0,M_1,M_2$ | 单Z基准 / 染色体信息Ridge / 16特征综合Ridge |
| $p_{ik}$ | 第 $i$ 条记录属于异常 $k$ 的概率 |
| $t_k,c_k$ | 判定阈值 |
| PR-AUC / ROC-AUC / F1 / Brier | 分类评价指标 |
| 孕妇级 cluster bootstrap | 以孕妇为整簇重抽样的置信区间方法 |

> 说明：Ridge 特征做 z-score 标准化，原始读段数、唯一比对读段数取 $\log(1+x)$；AB 为监督标签，AE 无类别变异不作标签。
