# 问题 1 公式汇总（论文编写用）

> 本文集中了问题 1 用到的全部公式：相关性分析、关系建模、显著性检验、模型选择。每条给出中文含义 + LaTeX 源码 + 直观形式。

---

## 一、Pearson 相关系数（回答"相关特性"）

Y 染色体浓度 $Y$ 与某个指标 $X$ 的线性相关强度：

**LaTeX**
```latex
r = \frac{\sum_{i}(X_i-\bar X)(Y_i-\bar Y)}{\sqrt{\sum_i(X_i-\bar X)^2}\,\sqrt{\sum_i(Y_i-\bar Y)^2}}
```

相关系数的显著性检验（$t$ 检验，自由度 $n-2$）：
```latex
t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}}
```

**直观形式**
$$t = \frac{r\sqrt{n-2}}{\sqrt{1-r^2}}$$

**实测结果**：$r(孕周)=0.127\ (p<0.001)$，$r(BMI)=-0.151\ (p<0.001)$，$r(年龄)=-0.119\ (p<0.001)$。

## 二、关系模型（5 个候选模型）

### M1 基准线性
```latex
Y = \beta_0 + \beta_1\,GA + \beta_2\,BMI + \varepsilon
```

### M2 多元线性（最终主模型）
```latex
Y = \beta_0 + \beta_1\,GA + \beta_2\,BMI + \beta_3\,Age + \varepsilon
```

### M3 对数-对数（捕捉非线性/饱和）
```latex
\ln Y = \beta_0 + \beta_1\ln GA + \beta_2\,BMI + \varepsilon
```

### M4 交互项
```latex
Y = \beta_0 + \beta_1\,GA + \beta_2\,BMI + \beta_3\,(GA\times BMI) + \varepsilon
```

### M5 混合效应（处理重复测量）
```latex
Y_{ij} = \beta_0 + \beta_1\,GA_{ij} + \beta_2\,BMI_i + u_i + \varepsilon_{ij}
```
其中 $u_i\sim N(0,\sigma_u^2)$ 为孕妇随机截距，$\varepsilon_{ij}\sim N(0,\sigma^2)$ 为残差。

## 三、参数估计（最小二乘 OLS）

线性模型 $Y=X\beta+\varepsilon$ 的系数估计：

**LaTeX**
```latex
\hat\beta = (X^\top X)^{-1} X^\top Y
```

---

## 四、显著性检验

### 单系数 t 检验
```latex
t_j = \frac{\hat\beta_j}{\mathrm{SE}(\hat\beta_j)},\qquad p_j = 2\big[1-F_{t}(|t_j|)\big]
```

### 整体 F 检验
```latex
F = \frac{SSR/k}{SSE/(n-k-1)} = \frac{(SST-SSE)/k}{SSE/(n-k-1)}
```

### 拟合优度
```latex
R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{\sum_i(Y_i-\hat Y_i)^2}{\sum_i(Y_i-\bar Y)^2}
```
```latex
\bar R^2 = 1 - (1-R^2)\frac{n-1}{n-k-1}
```

### 共线性诊断（方差膨胀因子）
```latex
\mathrm{VIF}_j = \frac{1}{1 - R_j^2}
```
其中 $R_j^2$ 是第 $j$ 个自变量对其余自变量回归的决定系数；$\mathrm{VIF}>10$ 视为严重共线。

**实测**：M2 的 $R^2=0.060$，调整 $R^2=0.057$，$F=22.84\ (p<0.001)$；VIF 均约 1.0（无共线性）。

## 五、模型选择

### 信息准则
```latex
\mathrm{AIC} = -2\ln L + 2k,\qquad \mathrm{BIC} = -2\ln L + k\ln n
```

### 交叉验证均方根误差
```latex
\mathrm{RMSE} = \sqrt{\frac{1}{n}\sum_i(\hat Y_i - Y_i)^2}
```

### 对数响应模型的 Jacobian 校正（M3 与其它模型比较 AIC/BIC 时）
M3 的响应是 $\ln Y$，换算到 $Y$ 尺度需加 Jacobian：
```latex
\mathrm{AIC}_{Y} = \mathrm{AIC}_{\ln Y} + 2\sum_i \ln Y_i,\qquad \mathrm{BIC}_{Y} = \mathrm{BIC}_{\ln Y} + 2\sum_i \ln Y_i
```

## 六、残差诊断

残差定义为 $e_i = Y_i - \hat Y_i$。

- **正态性**：Shapiro-Wilk 检验统计量 $W$（$p>0.05$ 满足正态）。
- **同方差性**：Breusch-Pagan 检验（$p>0.05$ 满足同方差）。
- **图示**：残差 Q-Q 图、残差-拟合值散点图、残差直方图。

---

## 七、混合效应模型的组内相关（ICC）

用于判断"重复测量是否不可忽略"：

```latex
\mathrm{ICC} = \frac{\sigma_u^2}{\sigma_u^2 + \sigma^2}
```

**实测**：$\mathrm{ICC}=0.739$，说明同一孕妇的重复测量之间存在较强相关性，混合效应模型 M5 的标准误更可靠；其固定效应方向（GA 正、BMI 负）与 M2 一致，结论稳健。

## 八、最终拟合结果（直接引用）

**主模型 M2（多元线性）**
```latex
Y = 0.1509 + 0.00125\,GA - 0.00196\,BMI - 0.00109\,Age
```
三个系数均 $p<0.001$。含义：孕周每增加 1 周，Y 浓度平均上升 $0.00125$；BMI 每增加 1，Y 浓度平均下降 $0.00196$。

**混合效应模型 M5（稳健性）**
```latex
\hat Y = 0.0696 + 0.00313\,GA - 0.00138\,BMI \quad(\text{组内效应})
```
