# 问题 3 符号设定

| 符号 | 含义 |
|---|---|
| $T_i^*$ | 第 $i$ 位孕妇的达标时间（Y浓度首次 ≥ 4% 的孕周，周） |
| $BMI$ / $age$ / $height$ / $weight$ | 身体质量指数 / 年龄 / 身高 / 体重 |
| $gravidity$ / $parity$ | 孕次 / 产次 |
| $\alpha,\beta,\sigma$ | AFT 对数正态模型参数：$\log T^*=\alpha+\beta\cdot BMI+\sigma\varepsilon$ |
| $F_G(t)$ | 组混合达标比例 = 组内个体达标概率的平均 |
| $q$ | 决策可靠度阈值（主结果 q=0.95） |
| $\sigma_Y$ | Y浓度单次测量误差（标准差） |
| $K$ | BMI 分组数 |
| $b_1,\dots,b_{K-1}$ | BMI 有序切点 |
| 左/区间/右删失 | 达标时间的三种观测情形 |

> 说明：候选模型变量做 z-score 标准化后进入模型（如 BMI_z、age_z），故主模型系数为标准化尺度。
